# Agent A - drug plan

Group policy: a drug gets a group when that group's lecture teaches it as therapy OR stresses it as
a contraindication/caution in that setting (e.g. verapamil "not for CHF", ISA blockers "Worsen!!!").
Deck-review questions and one-line recap lists do not add a group.
Groups: AA = Antiarrhythmics, AN = Angina, HF = Heart failure, LL = Lipid-lowering.
